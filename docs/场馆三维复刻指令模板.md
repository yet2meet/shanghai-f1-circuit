# 场馆三维复刻 · 指令模板

> 用法：复制下面「指令正文」整段发给 Claude，只改【方括号】里的内容。
> 适用于 F1 赛道、球场、体育馆、演出场馆等任何需要 1:1 还原的场馆。
> 本模板由「上海国际赛车场」项目的做法整理而来。

---

## 指令正文（复制这一段）

```
请帮我做一个【场馆名称】（【城市 / 国家】）的三维网页复刻，1:1 还原真实场馆。

【项目情况】（二选一）
- 新建项目：技术栈与上海国际赛车场项目相同（Vite + three.js，部署到 Cloudflare Pages）。
- 在现有项目里加：项目目录是【路径】。

【赛事 / 时间基准】【如：2026 年 F1 日本大奖赛，正赛 4 月 5 日 14:00 当地时间；或：2026 赛季中超主场】

【我要的建筑和内容】
1. 【例：主看台（上下两层）】
2. 【例：维修楼 / P 房内部】
3. 【例：各弯道看台 / 球场四面看台】
4. 【例：场外道路、地铁站、停车场】
5. 【……按需增减】

【必须遵守的原则】

一、真实性：查得到才做，查不到不做
- 位置、尺寸、形状优先用 OpenStreetMap 真实测绘数据（轮廓、高度 height / min_height、道路、水系、隧道、天桥）。
- 数量、容量、层数、年份用官方资料或可靠报道核对（例如“可容纳 4000 余名观众”“分上下两层、共 20 排”）。
- 每一处“按资料确定”的细节，都在代码注释里写明出处；回复里附上来源链接。
- 查不到或说法冲突的（例如杆位在哪一侧、某个广告在哪个弯），不要猜，先不做，并告诉我缺什么。
  能用照片确认的，告诉我需要什么样的照片或转播截图。
- 品牌 / 赞助商：只放已确认的（如赛事冠名、官方计时），用文字字样，不复制标志图片；
  在“关于”页注明商标归各自权利人，不代表合作或背书。

二、建筑造型
- 弯曲的看台、建筑必须做成圆滑连续的整体（沿平滑曲线整体扫掠），不能用一段段方块拼接；
  座位沿每排自己的弧线排布，过道径向，栏杆、玻璃栏板、挡墙、后墙沿弧连续。
- 现实中分上下层的看台，模型也要分层（票区不分可以不分）。
- 每条过道都要有出入口（通道口）。
- 座位数要和官方容量对得上；对不上就调整排数并说明。
- 室内（如 P 房 / 更衣室 / 包厢）按真实用途精细化：设备、屏幕界面、人员、明暗；远处自动隐藏细节。
- 适当加入工作人员 / 观众，不只局限在室内。

三、光影与材质
- 白天太阳按赛事 / 比赛时刻的真实方位（按经纬度、日期、时刻算高度角和方位角）。
- 软阴影；阴影范围要覆盖镜头附近，斜看时近处也要有影子。
- 材质用程序生成的纹理（沥青、草、砂石、混凝土、屏幕界面等），不依赖大图片；昼夜两种模式都要好看。

四、性能
- 大量重复物体用实例化（InstancedMesh）或合并几何；远处用简化版本。
- 手机端也要流畅：控制面数，必要时自动降画质。

【工作方式】
- 中文回复。每完成一部分，在浏览器预览里自己核对（白天 / 夜间、近景 / 远景），截图确认没有报错再汇报。
- 汇报时说清楚：做了什么、依据是什么、哪些没核实、哪些因为查不到而没做。
- 构建通过后【直接提交并推送 / 先问我再提交】。提交信息用中文。
```

## 可选补充（需要时加进指令正文）

| 想要的效果 | 可以加这一句 |
| --- | --- |
| 指定参考照片 | 「我会发几张实景照片，请以照片为准还原外观、配色和细节。」 |
| 还原广告布置 | 「按【年份】转播画面还原赛道广告，我会发截图，只放截图里看得清的。」 |
| 票价 / 座位图 | 「票区和票价按【官方票价表名称】，颜色沿用官方座位图。」 |
| 夜赛场馆 | 「这是夜赛，夜间灯光是重点：灯塔位置按实景，照度要均匀。」 |
| 球场草坪 | 「草坪修剪条纹按实景方向和宽度，球门、角旗、替补席都要有。」 |
| 只做局部 | 「这次只做【某个区域】，其他保持现状。」 |

## 填写示例

```
请帮我做一个铃鹿赛道（日本三重县）的三维网页复刻，1:1 还原真实场馆。
【项目情况】新建项目，技术栈与上海国际赛车场项目相同。
【赛事 / 时间基准】2026 年 F1 日本大奖赛，正赛当地时间 14:00。
【我要的建筑和内容】
1. 主看台与维修楼（含 P 房内部）
2. 8 字形立交桥（赛道上下交叉处）
3. 摩天轮与游乐园
4. S 弯、130R、发卡弯旁的看台
（以下原则与工作方式同模板）
```
